# 2026-04-01 矩阵乘法耗时小实验

## 实验目的
观察不同输入规模下，矩阵乘法耗时如何变化，为后续 PyTorch profiling 和 attention benchmark 做准备。

## 实验方法
- 使用 NumPy 的 `np.dot()` 做矩阵乘法
- 输入规模：`100, 200, 500, 1000, 2000`
- 每个规模重复运行 5 次
- 使用 `time.perf_counter()` 记录耗时
- 只测矩阵乘法本身，不统计随机生成矩阵的时间

## 实验结果

| Input size | Run count | Average time (s) |
|------------|-----------|------------------|
| 100x100    | 5         |                0.000079s  |
| 200x200    | 5         |                  0.000220s|
| 500x500    | 5         |          0.007708s        |
| 1000x1000  | 5         |       0.013228           |
| 2000x2000  | 5         |       0.118576s           |

## 实验结论
- 随着矩阵规模增大，矩阵乘法耗时明显增加。
- 大矩阵下耗时增长更快，说明输入规模对性能影响显著。
- 这为后续 attention 和 profiling 实验提供了最小基础。
